# Legacy Archive (`legacy/`)

This directory preserves the original pre-audit versions of datasets, data generation scripts, machine learning evaluation scripts, simulation engines, spatial pipelines, and result tables prior to the scientific reproducibility and audit remediation of CoralTwin-DT.

## Archived Artifacts

### 1. Data & Provenance (`legacy/03_Data/`)
- `03_Data/final_dataset.csv`: Original 30-station ($N = 15,000$) dataset containing legacy provenance tags (`4,077` rows labeled `"Real_Observation_Calibrated"` [27.18%] and `10,923` rows labeled `"Digital_Twin_Simulated"` [72.82%]), all of which were generated synthetically via `np.random` (`SEED = 42`).
- `03_Data/processed_data/coral_environmental_harmonized.csv`: Original 25-station ($N = 12,500$) dataset generated by `generate_datasets.py` with different station counts and stochastic noise parameters (`Coral_Cover_Loss_Pct` slope `0.78`, $\sigma = 4.0$).
- `03_Data/build_final_dataset.py`: Original 30-station generator script.
- `03_Data/generate_datasets.py`: Original 25-station generator script.
- `03_Data/metadata/data_source_manifest.json`: Pre-unification manifest splitting 25 active and 5 archived stations.

### 2. AI & Modeling (`legacy/06_AI_and_Modeling/`)
- `06_AI_and_Modeling/machine_learning/train_models.py`: Original training script that read the 25-station ($N = 12,500$) dataset and contained hardcoded `benchmark_rows` for CNN-LSTM and PINN.
- `06_AI_and_Modeling/model_evaluation/evaluate_models.py`: Original evaluation script that used 5-fold random `KFold` over station indices without enforcing a 25 km spatial buffer and included post-target benthic variables (`Structural_Rugosity`, `Live_Coral_Cover_Pct`, `Macroalgae_Cover_Pct`, `Shannon_Diversity_H`).
- `06_AI_and_Modeling/compare_rf_xgb_lstm.py`: Original comparison script that included `Shannon_Diversity_H` (a zero-noise deterministic linear function of `Coral_Cover_Loss_Pct`) in $X$, causing reverse target leakage ($R^2 = 0.9995$, $\text{RMSE} = 0.346\%$), and used `MLPClassifier`/`MLPRegressor` as a proxy labeled `"LSTM_Deep_Learning"`.
- `06_AI_and_Modeling/model_evaluation/model_benchmark_metrics.csv`: Pre-audit benchmark table containing hardcoded CNN-LSTM/PINN rows.

### 3. Scenarios, GIS & Results (`legacy/07_Scenarios_and_Simulations/`, `legacy/08_GIS_and_Remote_Sensing/`, `legacy/09_Results/`)
- `07_Scenarios_and_Simulations/simulation_engine.py`: Original Monte Carlo decadal scenario engine.
- `08_GIS_and_Remote_Sensing/spatial_pipeline.py`: Original 25-station spatial prioritization pipeline ($N = 2,000$ grid cells).
- `09_Results/tables/Table1_model_performance_benchmarks.csv`: Original Table 1 with unverified hardcoded metrics.
- `09_Results/tables/Table2_decadal_scenario_projections.csv`: Original Table 2 decadal projections.
- `09_Results/tables/Table3_spatial_restoration_priority.csv`: Original Table 3 (25 stations).
