# Contributing to CoralTwin-DT

Thank you for your interest in contributing to **CoralTwin-DT**! As an open-source, reproducible scientific digital twin project, we welcome contributions from marine ecologists, remote sensing specialists, software engineers, and data scientists worldwide.

---

## 1. Code of Conduct & Open Science Principles
- **Reproducibility First:** All contributions altering data processing, biophysical equations, or AI models must be validated using `python run_all.py` to ensure deterministic execution (`SEED = 42`).
- **FAIR Compliance:** Any new environmental variables or datasets must include standard ISO-19115 metadata in `03_Data/data_dictionary_final.csv`.
- **Scientific Attribution:** All synthetic records generated by computational subroutines must include the mandatory attribution disclaimer:  
  `"Resultado obtenido mediante prototipo computacional del gemelo digital"`.

---

## 2. Development & Contribution Workflow

```text
Fork Repository -> Create Topic Branch -> Make Changes & Run Tests -> Commit (Conventional Commits) -> Open Pull Request
```

### Step-by-Step Instructions:
1. **Fork the Repository** on GitHub: [https://github.com/HrSly11/CoralTwin-DT](https://github.com/HrSly11/CoralTwin-DT).
2. **Clone your fork locally**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/CoralTwin-DT.git
   cd CoralTwin-DT
   ```
3. **Create a clean virtual environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: .\venv\Scripts\activate
   pip install -r 12_Reproducibility/requirements.txt
   ```
4. **Create a dedicated feature branch**:
   ```bash
   git checkout -b feat/your-feature-name
   ```
5. **Make your modifications** and verify that the full pipeline executes cleanly:
   ```bash
   python run_all.py
   ```
6. **Commit your changes** using [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat(scope): add new telemetry connector for Sentinel-3 OLCI`
   - `fix(biophysics): adjust aragonite solubility coefficient for salinity extremes`
   - `docs(reproducibility): update docker container instructions`
7. **Push to your fork and submit a Pull Request (PR)** against the `main` branch.

---

## 3. Reporting Issues & Proposing Features
- **Bug Reports:** Please provide your OS, Python version, terminal traceback, and steps to reproduce.
- **Data Requests:** For new regional reef pilot stations, submit station coordinates, geomorphic zoning, and climatological MMM in a GitHub Issue.
- **GitHub Issues:** [https://github.com/HrSly11/CoralTwin-DT/issues](https://github.com/HrSly11/CoralTwin-DT/issues).
