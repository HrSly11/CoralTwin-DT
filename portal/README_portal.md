## 1. Quick-Start (< 5 seconds)

### Method A: Using the Built-in Python Server
```bash
python portal/server.py
```
*Your default browser will automatically open at `http://localhost:8000`.*

### Method B: Standalone Direct File
Double-click `portal/index.html` in your file explorer to open it directly in any modern browser (Chrome, Edge, Firefox, Safari) with zero setup required.

## 3. Interactive Command Center Features

1. **Procedural 3D WebGL Coral Colony:**
   - Rotate, pan, and zoom around a 3D branching scleractinian coral mesh.
   - Adjust the environmental sliders (SST, DHW, pH) to watch the coral transition dynamically from **Healthy Symbiont Green-Brown** $\to$ **Heat Shock Fluorescing Pink** $\to$ **Bleached Skeleton Chalk-White**.
2. **ESRI Ocean Bathymetry Satellite Map:**
   - 30 global monitoring stations with pulsing beacons colored by real-time bleaching risk.
   - Click any station to automatically synchronize all telemetry sliders, HUD cards, and 3D models.
3. **Real-Time Machine Learning Sandbox (XGBoost + TreeSHAP):**
   - Instant sub-millisecond AI inference of bleaching risk categories and estimated coral cover loss %.
   - Live TreeSHAP horizontal bar chart detailing positive vs negative marginal attributions.
4. **2025–2050 Decadal Forward Simulation Sandbox:**
   - Interactive Runge-Kutta 4th Order ODE solver simulating community competition through 2050.
   - Test custom management interventions: warming rates, active outplanting %, thermal hardening bonuses (+2.0°C), and MPA herbivore grazing ($g$).
5. **Spatial Restoration Priority Matrix (SRPI):**
   - Filterable, searchable table ranking stations across Tier 1, Tier 2, and Tier 3 management zones.
   - Push-button download for `priority_restoration_zones.geojson`.
